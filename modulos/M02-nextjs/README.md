# M02 — Next.js

[← Página anterior](../../demos/spa/guia/05-la-comparacion.md) · [Siguiente página →](01-primera-vista/01-html-vacio.md)

Next.js no sustituye a React. Cambia **dónde se fabrica el HTML**. Este módulo separa el problema de la primera vista, las dos formas de fabricarla (en cada visita o de antemano) y el criterio para pedir Next.js o dejar React solo en el navegador. La guía de la demo recorre la portada y la página de cliente con el código fuente delante.
