[← Página anterior](../../README.md) · [Siguiente página →](01-pagina-tradicional/01-el-documento.md)

Este módulo separa cuatro cosas que en una propuesta suelen ir en el mismo párrafo: la página tradicional, la SPA, React como biblioteca, y el entorno (Node, NPM, Angular, Vue). Cada una tiene sus páginas. Las dos guías del final recorren las demos con el detalle de lo que se ve y de lo que significa.
