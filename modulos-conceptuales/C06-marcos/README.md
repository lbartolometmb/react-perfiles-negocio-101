# C06 — Next, Gatsby y Remix

[← Página anterior](../C05-calidad/04-senales-de-alerta.md) · [Siguiente página →](01-cuando-nace-el-html.md)

Objetivo: comparar los marcos que se apoyan en React y saber cuál pide el problema.

React describe las piezas. Un marco decide cuándo nace el HTML, cómo se pide el dato y cómo se organizan las rutas. Next.js, Gatsby y Remix son tres respuestas distintas. Next es la que la propia documentación de React señala como punto de partida habitual. Las otras dos siguen apareciendo en propuestas, y conviene leerlas con el mismo criterio.
