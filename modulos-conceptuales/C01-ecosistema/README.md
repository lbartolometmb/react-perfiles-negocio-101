# C01 — El ecosistema

[← Página anterior](../README.md) · [Siguiente página →](01-evolucion.md)

Objetivo: entender el ecosistema y por qué React aparece en una propuesta.

React no llega solo. Llega después de una forma de hacer páginas, al lado de otras bibliotecas parecidas, y siempre con un taller (Node y NPM) que prepara lo que el servidor web va a entregar. Este módulo separa esas piezas para que una frase comercial se pueda desmontar.
