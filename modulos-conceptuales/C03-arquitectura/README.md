[← Página anterior](../C02-pensar-en-la-interfaz/05-lectura-guiada.md) · [Siguiente página →](01-la-estanteria.md)

Objetivo: entender cómo se estructura un proyecto real, sin recorrer todavía sus ficheros.

El árbol del boceto crece hasta ser un proyecto: carpetas, piezas que deciden y piezas que pintan, recuerdos en tres sitios posibles, y una visita —aparece, se actualiza, se va— que los hooks solo enchufan.
