# C05 — Calidad y revisión

[← Página anterior](../C04-sistemas/04-en-la-empresa.md) · [Siguiente página →](01-lo-que-se-nota.md)

Objetivo: tener con qué validar y auditar un proyecto sin convertirse en quien lo programa.

La calidad se nota en la pantalla y se confirma con unas pocas preguntas. Las herramientas —pruebas, React DevTools— sirven para sostener la respuesta, no para sustituirla.
